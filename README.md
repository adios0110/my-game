## 게임 아이디어
제목: 스펠 컬렉션
한 줄 설명: 플레이어가 위에서 내려오는 글자들을 모아서 단어를 만들면서 하는 게임
플레이어가 하는 일: 제한된 시간 안에서 이상 글자(장애물)를 피하고 글자를 많이 모아 최대한 많은 단어를 만들어 점수를 얻는 것
게임이 끝나는 조건: 이상 글자(장애물)에 닿아 체력 3개가 없어지거나 단어를 만들지 못해 시간이 연장되지 않고 다 흘렀을 때

선정 이유: 순간적으로 아이디어가 떠올라서 쓴 게임이기 때문이다.
