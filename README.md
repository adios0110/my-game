## 게임 아이디어
제목: 스펠 컬렉션
한 줄 설명: 플레이어가 위에서 내려오는 글자들을 모아서 단어를 만들면서 하는 게임
플레이어가 하는 일: 제한된 시간 안에서 이상 글자(장애물)를 피하고 글자를 많이 모아 최대한 많은 단어를 만들어 점수를 얻는 것
게임이 끝나는 조건: 이상 글자(장애물)에 닿아 체력 3개가 없어지거나 단어를 만들지 못해 시간이 연장되지 않고 다 흘렀을 때

선정 이유: 순간적으로 아이디어가 떠올라서 쓴 게임이기 때문이다.

4주차
- 플레이어 캐릭터와 배경 장애물 이미지 추가 및 장애물 움직임 추가

5주차
- 플레이어 캐릭터를 A,D를 통해 좌우로 움직일 수 있게 했고 스페이프로 점프 조작 가능하게 함.

6주차
- 장애물과 플레이어가 충돌하면 점수가 깎이게 설정함.
- a,d로 좌우로 움직이고 스페이스 바로 점프 하면서 장애물에 해당하는 빨간 기호들을 피해 문자들을 먹어 조합해 단어를 완성하면 점수를 얻는다.

7주차
- 디버깅 과정을 통해 게임이 어떻게 고장이 나고 고치는 지 알 수 있었다.
